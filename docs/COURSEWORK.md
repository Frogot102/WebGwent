# WebGwent — материалы к курсовой

## 1. Цель

Реализовать веб-приложение для игры в Гвинт (правила TW3) на языке C#, с возможностью игры против бота, вдвоём на одном устройстве и онлайн.

## 2. Архитектура

- **WebGwent.Game** — доменная логика без UI. `RulesEngine` применяет ходы к `MatchState`. Подсчёт силы — `ScoreCalculator`. Карты загружаются из embedded JSON (`Data/cards.json`) через `CardCatalog`.
- **WebGwent.Server** — Blazor Server (интерактивный рендер). Локальные режимы вызывают `GameSessionManager` напрямую. Онлайн — `GameHub` (SignalR), источник истины на сервере; клиентам уходит `MatchView` (без чужой руки).
- **WebGwent.Tests** — проверка каталога, валидации колод, правил TW3 (кристаллы, лидеры, Muster, Испепеление по ряду, Mardroeme, Чучело), поведения бота и бенчмарк бота.

```
Browser → Blazor / SignalR → GameSessionManager → RulesEngine → MatchState
```

## 3. Игровой цикл

1. Создание матча из двух валидных колод, раздача по 10 карт.
2. Муллиган (до 2 замен). Scoia'tael выбирает, кто ходит первым.
3. Ходы: сыграть карту / пас / способность лидера; при необходимости pending-выбор (Agile, Medic, Decoy, ряд для Рога и Mardroeme, карты для лидеров).
4. Оба паса → подсчёт → проигравший теряет кристалл (при ничьей — оба; Nilfgaard выигрывает ничьи); фракционные эффекты между раундами.
5. У кого кончились кристаллы — проиграл; если у обоих сразу — ничья. Матч длится не больше 3 раундов.

## 4. Как устроен бот

Бот (`WebGwent.Game/Bot/BotAI.cs`) на каждом ходу делает три шага:

1. **Стратегия раунда.** По числу кристаллов, картам в руках и пасу соперника решает, нужен ли раунд:
   - первый раунд играется за преимущество в картах: сначала шпионы, пас при хорошем отрыве, сдача раунда, если отыгрываться дорого;
   - если раунд решающий, бот не пасует, пока соперник может догнать;
   - если соперник спасовал, бот ищет самый дешёвый набор ходов, который выигрывает раунд (перебор до 3 ходов в глубину).
2. **Оценка ходов.** Каждый возможный ход (карта, ряд, цель Чучела, лидер) разыгрывается на копии матча. Оценка = изменение счёта + ценность полученных карт − ценность потраченных + отложенные эффекты (погода и Рог действуют на ещё не сыгранные карты).
3. **Просчёт вперёд (Монте-Карло).** До 10 лучших ходов и пас проверяются доигрыванием матча до конца в 32 вариантах. В каждом варианте рука соперника заново раздаётся из его неизвестных карт, а своя колода перемешивается. Партии доигрываются быстрой политикой `RolloutPolicy`. Бот выбирает ход, который чаще приводит к победе. Ход занимает около 30 мс.

Бот не подглядывает руку соперника и порядок колод: добор оценивается как средняя карта колоды.

Бенчмарк `BotBenchmarkTests` играет все пары фракций с обеих сторон против прежней версии бота. На 400 партиях новый бот набирает около 84% (было 60% у первой версии без просчёта вперёд).

## 6. Запуск и требования

- .NET 10 SDK
- Браузер с поддержкой WebSockets (для онлайн)

```bash
dotnet run --project WebGwent.Server
dotnet test
```
