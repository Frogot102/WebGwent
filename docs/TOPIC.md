# Описание темы курсовой работы

**Тема:** веб-приложение для пошаговой карточной стратегии с искусственным интеллектом и сетевой игрой.

**Рабочее название:** WebGwent  
**Платформа:** C# / .NET, Blazor Server, SignalR  
**Язык интерфейса:** русский и английский

---

## Суть проекта

Разрабатывается браузерное приложение, в котором два участника (человек и программа или два человека онлайн) проводят партию в пошаговой карточной игре. Игроки составляют колоды, выкладывают карты на поле по рядам, учитывают особые эффекты карт и соревнуются по очкам силы в нескольких раундах. Победитель определяется по запасу «жизней» (кристаллов) и итогам раундов.

Проект ориентирован на учебную демонстрацию полного стека: доменная логика игры, веб-интерфейс, взаимодействие в реальном времени, учётные записи пользователей и автоматические тесты.

---

## Цели работы

1. Реализовать **движок правил** партии (ход, пас, подсчёт очков, смена раунда, победа/поражение/ничья) отдельно от интерфейса.
2. Сделать **веб-клиент** на Blazor Server: меню, сборка колоды, поле боя, справка по правилам, профиль.
3. Реализовать **бота-соперника** с несколькими уровнями сложности (эвристики и просчёт вариантов ходов).
4. Обеспечить **онлайн-матч** двух игроков через SignalR (общая комната, синхронизация состояния на сервере).
5. Добавить **учётные записи**, историю матчей, демо-модель подписки (доступ к сложным режимам и сетевой игре) и набор юнит-тестов.

---

## Что демонстрирует проект (для оценки темы)

| Область | Содержание |
|--------|------------|
| Архитектура | Разделение на библиотеку правил (`WebGwent.Game`), веб-сервер с UI (`WebGwent.Server`) и тесты (`WebGwent.Tests`) |
| Алгоритмы | Оценка ходов, симуляция партии, упрощённый look-ahead / Monte Carlo для бота |
| Сеть | Real-time обмен через SignalR, сервер как источник истины |
| Веб-UI | Интерактивный Blazor, адаптивная вёрстка, локализация |
| Качество | Автотесты механик и поведения бота |

---

## Режимы использования

- игра против бота (несколько уровней сложности);
- сетевая игра двух пользователей;
- конструктор и проверка колод;
- справочник правил с поиском;
- профиль, подписка (учебная демо-оплата / инвайт-коды), история результатов.

---

## Структура решения

```
WebGwent.Game    — правила, каталог карт, бот, состояние матча
WebGwent.Server  — Blazor UI, SignalR Hub, аккаунты
WebGwent.Tests   — юнит-тесты и бенчмарк бота
```

**Запуск:** `dotnet run --project WebGwent.Server`  
**Тесты:** `dotnet test`

---

## Почему тема подходит для курсовой

Тема сочетает проектирование предметной области (правила и состояние матча), алгоритмы принятия решений (ИИ соперника), современный веб-стек (.NET / Blazor) и сетевое взаимодействие. Объём достаточен для курсовой: от модели данных и движка до рабочего интерфейса, онлайн-режима и тестов.
