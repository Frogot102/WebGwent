# WebGwent

Курсовая работа: веб-порт **Гвинта** из *The Witcher 3: Wild Hunt* на **C# / Blazor Server**.

## Возможности

- Полный цикл матча по правилам TW3: муллиган, у каждого 2 кристалла, проигрыш или ничья в раунде стоит кристалл, максимум 3 раунда, возможна ничья в матче
- Все карты TW3 вместе с дополнениями «Каменные сердца» и «Кровь и вино», включая Шторм Скеллиге и 22 лидера
- Механики: погода, Decoy, Scorch, Commander's Horn (с выбором ряда), Spy, Medic, Tight Bond, Morale Boost, Muster, Agile, Berserker и Mardroeme
- Карты в руке и на рядах отсортированы по силе; бот отвечает с паузой после хода игрока
- Фракционные пассивы: Northern Realms, Nilfgaard, Scoia'tael, Monsters, Skellige
- Сложности бота: **Лёгкая**, **Средняя**, **Высокая** (полный ИИ), **На смерть** (усиленный look-ahead)
- **WebGwent Plus**: без рекламы, сложности Высокая / На смерть, онлайн PvP; демо-покупка и инвайт-коды в профиле
- Режимы: **против бота** (всем на Лёгкой/Средней), **онлайн PvP** (SignalR, только Plus)
- Справочник `/rules` с поиском, сортировкой и сворачиваемыми главами
- Пресет-колоды всех 5 фракций + валидация
- Карты показаны целиком, как в TW3, на русском или английском — по языку сайта: текущая сила — на самой карте, ряд — цветом подсветки; по клику справа полное описание того, что делает карта

Вшитый админ (роль Admin, Plus без подписки): логин **`admin`**, пароль **`admin123`**.  
Создаётся/обновляется при каждом запуске (`BuiltInAdmin` + `SeedAdmin` в `appsettings.json`). На странице входа есть подсказка.

## Запуск

Нужны **два** процесса — API и UI:

```bash
dotnet restore
dotnet run --project WebGwent.Api
dotnet run --project WebGwent.Server
```

Или Docker:

```bash
cp .env.example .env   # задайте JWT_KEY и ADMIN_PASSWORD
docker compose up --build
```

UI: http://localhost:5097 · API: http://localhost:5180  
Endpoint’ы: [docs/API.md](docs/API.md). Демо к защите: [docs/DEMO.md](docs/DEMO.md).

Тесты:

```bash
dotnet test
```

## Структура

| Проект | Назначение |
|--------|------------|
| `WebGwent.Game` | Движок правил, каталог карт, бот, сессии |
| `WebGwent.Api` | REST + SignalR (JWT), аккаунты, матчи, колоды |
| `WebGwent.Server` | Blazor UI — клиент API |
| `WebGwent.Tests` | Юнит-тесты механик, поведения бота и бенчмарк бота |

Подробности для пояснительной записки: [docs/COURSEWORK.md](docs/COURSEWORK.md).

## Иллюстрации карт

Картинки в `WebGwent.Server/wwwroot/img/cards` — лицевые стороны карт Гвинта из *The Witcher 3*
(уменьшены до 260 px, WebP): английские — с [Witcher Wiki](https://witcher.fandom.com), русские
(в `img/cards/ru`, под теми же именами) — с [русской Ведьмак Вики](https://witcher.fandom.com/ru).
Язык карт переключается вместе с языком сайта (РУ/EN). Русские названия карт в интерфейсе — официальные
из русской версии игры (после патча 4.04). Русские карты в вики сделаны до этого патча, и на 18 из них
напечатано старое название («Василиск», «Лучник Бурой Хоругви», «Вампиры: брукса», перепутанные титулы
Эредина…) — поверх него подписано нынешнее. У Корала и Нильфгаардского рыцаря нет карты из TW3, для них
взят арт из отдельной игры GWENT; у Ширру и «Фольтест: Завоеватель» нет русской карты в вики, поэтому их
названия по-русски подписаны поверх английских, а у второй баллисты — русская карта первой (другой арт).
Соответствие карт и картинок — в `WebGwent.Server/Services/CardArt.cs`; у пользовательских карт из
админки картинки нет.

Карта показывается целиком; поверх печатного кружка рисуется только текущая сила (зелёная — выше
исходной, красная — ниже). На поле карта всегда по высоте своего ряда, а когда ряд заполнен, карты
наезжают друг на друга, как в TW3. Описания способностей в панели осмотра написаны своими словами.
